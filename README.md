# ui-icons-hub · UI Icons & Design Resources

One-stop **open-source SVG icon aggregation**: we collect permissively-licensed
icon libraries scattered across GitHub, normalize and chunk them, and pair them
with a search engine (`Apache-2.0` FlexSearch) that understands **Chinese
intent**. Preview online, copy SVG source, download `.svg` files — right in the
browser.

> Icon artwork remains the property of each upstream project. This site ships
> **no unified license** for the assets — always check each collection's own
> upstream license (see the listing below and [`LICENSE`](LICENSE)).

## How to search

- Chinese keywords work: queries such as "shopping cart", "gear", "chart",
  "gamepad", "sun", "currency" (and their Chinese equivalents) … all resolve to the
  matching English icon names.
- Fuzzy English works too: `cart` → `cart-shopping` / `shopping-cart` / `carthrottle`;
  even a prefix like `sh` suggests `shopping-cart`.
- Data chunks load on demand **after** a hit — searching never downloads entire
  collections you don't need.
- Results are ranked by exact-name > prefix > word-boundary > substring, so the
  most likely match comes first.

### Desktop clients

| Edition | macOS | Windows | Linux | Size |
| --- | --- | --- | --- | --- |

The online build ships only the shell and search index; data is fetched from
the repo on demand and cached locally. The offline build bundles all 215
collections and works with no network. Both carry identical content; packages
are built locally with `tools/pack_desktop.py` and attached to the GitHub
Release.
