# Farewell · UI 图标与设计资源库

一站式 **UI 图标与设计资源聚合平台** —— 汇集主流开源图标库、技术栈品牌 Logo、AI 大厂视觉与 Web UI 设计系统，全部以 **SVG 图标/资源包** 形式在线可查、可复制、可下载。

## 资源规模

- 🧩 **67 套** 开源 SVG 图标库
- 📊 **80,492 个** 图标
- 🛠️ **189 个** 技术栈品牌（Simple Icons / Devicon / Skill Icons / VS Code Icons...）
- 🤖 **38 个** AI 大厂图标 / Logo（OpenAI / Anthropic / Google / Meta...）
- 🎨 **186 个** UI 设计项目（Ant Design / Element Plus / Naive UI / shadcn/ui / Tailwind CSS...）

## 项目文件

- `index.html` — 项目主页（搜索、收藏/筛选、图标复制与下载）
- `icons.js` — `window.ICON_SETS`：图标数据集 + 来源 SVG（含当前颜色、深浅色）
- `kits.js` — `window.UI_KITS`：UI 组件库 / 小程序 / 图标设计系统 / 字体资源数据
- `data/` — 各图标库 JSON/JS 分片（通过 GitHub REST API 拉取，拉取日期 2026-09-20）
