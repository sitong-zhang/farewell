Use the icon library as a CDN

Add one script tag to search 215 icon sets · 345,961 SVG icons from any web page / CodePen / your own project, with intent-based search
← Back to the icon library
This page is a live demo of cdn.js — the search box and results below are really running (not a screenshot). Open the console to see which shards it loads on demand.

1. Include

<script src="https://cdn.jsdelivr.net/gh/sitong-zhang/ui-icons-hub@v1.0.0/cdn.js"></script>
Zero dependencies~10 KBIndex is 1.4 MB gzipped, fetched on first search You can also pin a version: swap @v1.0.0 for @main to always get the latest.

2. Usage

// Names and ownership only (fast, no icon data downloaded)
const list = await UIH.search('shopping cart');
// → [{ name:'cart', slug:'ionic-team__ionicons', set:'Ionicons', license:'MIT', ... }]

// Names plus SVG source (loads only the shards that matched)
const withSvg = await UIH.searchSvg('gear', { limit: 20 });
// → [..., svg:'<svg xmlns="..."><path .../></svg>']

// Fetch exactly one
const one = await UIH.icon('feathericons__feather', 'activity');

// See what's in the library
const sets = await UIH.list();          // 215 sets
const names = await UIH.names('tabler__tabler-icons');  // all icon names in one set

// Intent dictionary (183 entries), plug in your own
const syn = await UIH.synonyms();       // { 'shopping cart': ['cart','shopping-cart',...] }

4. Returned fields

aliasThe alias that matched, if any (otherwise null)

set / repoIcon set name / GitHub repo
licenseLicense of the icon set (MIT, CC0-1.0, Apache-2.0…)
homepageUpstream homepage, for attribution and tracing
groupgeneral / brand / emoji
monoWhether it is monochrome (recolors via the CSS color property)
svgReturned only by searchSvg / icon: the full SVG source

5. Notes & licensing

Why is there no direct link for a single SVG file? The 345,961 icons are packed into shards (thousands per file); generating a separate file per icon would add 350k files and about 1.5 GB to the repo, and hosts would rate-limit us. A single script with on-demand loading is easier to use than per-icon links and saves bandwidth.

Licensing: icon assets belong to their upstream projects and there is no single unified license — follow the upstream license of each set (the license field returned by UIH.search() is that license). See the repository README for the full list. This site's code and cdn.js are MIT.
