把图标库当 CDN 用

一行脚本引入，在任意网页 / CodePen / 你自己的项目里检索 215 套图标库 · 345,961 个 SVG 图标，支持中文意图
← 回到图标库
本页就是 cdn.js 的真实调用示例，下面的搜索框和结果是真的在跑（不是截图）。打开控制台能看到它按需加载了哪些分片。

1. 引入

<script src="https://cdn.jsdelivr.net/gh/sitong-zhang/ui-icons-hub@v1.0.0/cdn.js"></script>
零依赖约 10 KB索引 gzip 后 1.4 MB，首次检索时才拉 也可以锁版本：@v1.0.0 换成 @main 永远取最新。

2. 用

// 只拿名字和归属（快，不下载任何图标数据）
const list = await UIH.search('购物车');
// → [{ name:'cart', slug:'ionic-team__ionicons', set:'Ionicons', license:'MIT', ... }]

// 连 SVG 源码一起拿（会自动加载命中所在的分片，只加载那几个）
const withSvg = await UIH.searchSvg('齿轮', { limit: 20 });
// → [..., svg:'<svg xmlns="..."><path .../></svg>']

// 精确取一个
const one = await UIH.icon('feathericons__feather', 'activity');

// 看库里都有什么
const sets = await UIH.list();          // 215 套
const names = await UIH.names('tabler__tabler-icons');  // 某一套的全部图标名

// 中文意图词典（183 条），可自己接
const syn = await UIH.synonyms();       // { '购物车': ['cart','shopping-cart',...] }

4. 返回的字段

字段说明
name图标名，如 shopping-cart
alias若该结果是通过别名命中的，这里是别名（否则 null）
slug图标库 id，如 feathericons__feather，可直接传给 UIH.icon()
set / repo图标库名称 / GitHub 仓库
license该图标库的许可证（MIT、CC0-1.0、Apache-2.0…）
homepage上游官网，便于署名与溯源
groupgeneral / brand / emoji
mono是否为单色（可用 CSS color 改色）
svg仅 searchSvg / icon 返回，完整 SVG 源码

5. 说明与许可

为什么没有"单个 svg 文件的直链"？　345,961 个图标是按分片打包的（一个文件里几千个）， 要为每个图标生成一个独立文件会让仓库多出 35 万个文件、约 1.5 GB，托管方也会限流。 改成"一个脚本 + 按需加载"，用起来比逐个直链更方便，也省流量。

许可：图标素材版权归各上游项目所有，没有统一许可证，以每个集合上游的实际许可证为准（ UIH.search() 返回的 license 字段就是它的许可证）。 完整清单见仓库 README。 本站代码与 cdn.js 为 MIT。
