从栅格开始，而不是从按钮开始 布局

界面先定网格与间距刻度，再往里面塞内容：所有尺寸都落到刻度上，改版时才不会一改全崩。

密度：信息密度 ≠ 把字变小 密度

密度是每屏能承担的决策量，不是字号。表格类后台追求「一屏看清」，移动端追求「一屏一件事」。

  • 行高：紧凑 28–32px / 标准 40px / 触屏 48px；表格行内留够 ≥ 6px 的上下留白。
  • 触摸目标 ≥ 44×44 px（iOS 44pt、Android 48dp），即使视觉上的按钮只有 24px，也要把热区撑到 44。
  • 密集界面里，用分隔线不如用分组留白；留白是最省代码的分隔符。
  • 多列数据优先 tabular-nums（等宽数字），否则滚动时数字会左右跳。
rows 行布局 table 表格 list 列表

颜色：语义 > 好看 颜色

颜色不是装饰，是语义信号：危险、成功、警告、不可用，必须一眼区分。

  • 实用比例：背景/中性 60%、次级 30%、强调 10%。强调色只给「你希望用户点的那个」。
  • 对比度门槛：正文 4.5:1，大字号（≥18.66px 粗体或 ≥24px）与 UI 组件边界 3:1。
  • 状态色必须配形状或文案，不能只靠颜色区分——约 8% 男性有色觉障碍（红绿最常见）。
  • 深色模式：背景用 #0B0D17 这类带一点蓝的深灰而非纯黑；文字别用纯白 #FFF，用 #E8EBFF 更耐看。
  • 本仓库单色图标已统一 fill="currentColor"，一句 color: 就能随主题变色。

排版：层级靠对立，不靠凑层次 排版

字阶（type scale）控制在 5–7 档：太多等于没有层级。

层级字号行高用途
Caption121.5辅助说明、错误提示

Subtitle161.5卡片标题、段落小标题
H3201.4区块标题
H128–321.3页面主标题
  • 正文行宽控制在 45–75 个字符（中文约 30–40 字一行），超了阅读会丢行。
  • 中文正文用系统字（PingFang / 微软雅黑 / Noto Sans SC），别用 webfont 塞 8MB 中文全集。
  • 数字、金额、百分比统一 font-variant-numeric: tabular-nums。

图标：一套就够，别拼三种风格 图标

图标混风是廉价感的头号来源。选一套（本仓库 215 套任挑），全部从它取。

  • 同一视觉重量：24px 网格里，方形图标边长 20px、圆形直径 22px 才看起来一样大（圆形天性显小）。
  • 描边统一：一套图标只能有 一种 stroke-width（常见 1.5 或 2），别把别人的 1.25 混进来。
  • 尺寸只留三档：16 / 20 / 24，不要 17px 这种「再大一点点」。
  • 图标 + 文字间距 8px；图标按钮热区 ≥ 40×40。
  • 有意义的功能必须有 aria-label；纯装饰图标用 aria-hidden="true"，避免读屏重复朗读。
可直接抄：在本仓库搜到图标 → 复制 SVG 源码 → 粘贴即用（单色图标已用 currentColor，color 即可改色）。

状态与反馈：别让用户怀疑自己点没点上 状态

任何可交互元素至少要有：默认 / 悬停 / 按下 / 焦点 / 禁用 / 加载中 六种状态。

  • 焦点环（focus ring）对比度 ≥ 3:1，且不能被 overflow:hidden 裁掉；只做 :focus-visible，鼠标点击不出现。
  • < 300ms 的操作不要 loading；> 1s 才用转圈；列表首次加载用骨架屏比转圈体验好得多。
  • Toast 3–5 秒自消失，位置统一；成功类 3 秒足够，错误类要留够阅读时间或让用户手动关。
  • 空状态三件套：发生了什么 / 为什么 / 下一步怎么做。只写「暂无数据」的都属于偷懒。
  • 破坏性操作（删除、清空）二次确认，并把危险动词写在按钮上：「永久删除」而不是「确定」。
loader 加载 bell 通知 ban 禁用 shield 危险

表单与校验：让用户一次填对 表单

  • 标签不要做成 placeholder——填了就看不清写的是什么。标签在上方最稳（超窄容器再考虑左对齐）。
  • 校验时机：失焦即校验，不要在输入到第 2 个字就报「格式错误」。
  • 错误文案说人话并给出路：「邮箱格式不对」→「少了一个 @，例如 name@example.com」。
  • 必填用星号 + aria-required；整个表单错误汇总在顶部，字段错误贴着字段。
  • 键盘流：Tab 可达、Enter 提交、Esc 关闭浮层。
mail 邮箱 key 密码 user 用户 check 校验

无障碍不是选项，是质量线 a11y

  • 语义优先：按钮就是 <button>，不要 div + onclick 然后忘了键盘。
  • 纯色 Check 之外的信息一定要有第二通道（文案、形状、动效之一）。
  • 尊重 prefers-reduced-motion：动画、滚动视差、自动轮播在减弱动效时降级。
  • 支持 200% 缩放不丢内容；不要把关键按钮放在 position:fixed 里随视图消失。
accessibility 无障碍 eye 可见性 universe 通用

交付：让开发拿到就能用 交付

  • 图标导出为 SVG（去 title/meta/注释、fill="currentColor"、保留 viewBox 不要写死 width/height）。
  • 命名用 kebab-case + 语义：arrow-left 而不是 icon_12。
  • 设计 token 与代码变量同名（color.bg.subtle），别在设计稿里叫「浅灰 3」。
  • 九种状态、三档尺寸、明暗两套主题一次性给全，比事后补一半靠谱。
