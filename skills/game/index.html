先搞清楚：游戏 UI 服务的是「信息」，不是排版 定位

游戏 UI 的第一目标是让玩家在 0.2 秒内读懂当前状态，第二才是好看。任何遮挡视野、逼玩家在菜单里连翻三层才能操作的 UI 都是失败的。

  • 安全区：留出刘海/挖孔（顶部 44–59dp）、圆角、底部手势条（34dp）区域，别把血条顶到边上。
  • 核心操作区在拇指自然弧线内（左下 / 右下），而不是屏幕中间。
  • HUD 占用控制在视野的 20–25% 以内，其余留给游戏画面。

HUD 分层：先分类，再排位置 分层

层内容要点
背景层半透面板、渐变遮罩明 drawn 度 ≤ 30%，不要抢画面
信息层血量、弹药、计时、资源固定位置、永远可见、对比足够
操作层技能键、攻击、跳跃拇指可达、热区大、可自定义
反馈层伤害数字、拾取提示、大字串覆盖率短停留（< 800ms）、不挡关键区
  • 信息层的位置永远固定：血量在左上就是一直左上，别让它跟着场景动。
  • 反馈层遵循「快进快出」原则：出现快、消失快、互不重叠。
  • 重要数字下方压一层 1–2px 描边或深色渐变，保证任何背景上都读得清。

数值可视化：条、段、数字各有用法 数值

  • 长条：血量、能量这类连续且需要「还剩多少」直觉的数值。
  • 分段：弹药、充能、回合数——离散可读比精确重要。
  • 数字：伤害、金币、分数；务必 tabular-nums 并加描边。
  • 长条掉血用「延迟白条」表现损失量，能显著提升感知清晰度。
  • 颜色之外加形状/图标辅助：红绿色盲玩家读不出「毒 vs 治疗」。

图标语义：一眼可辨 > 好看 图标

  • 技能/道具图标轮廓优先：48×48 缩略到 40px 仍能辨认才算合格（尝试灰度化检查）。
  • 三态必须区分：可用 / 冷却中 / 不可用——用去饱和 + 半透明遮罩 + 倒计时数字。
  • 同一功能在不同界面用同一图标，「返回」别一会儿箭头一会儿叉。
  • 状态图标（中毒、燃烧、减速）风格要和道具图标区开，避免混淆。
  • 本仓库的 Game Icons（4,134 个，CC BY 3.0） 与各类 UI 套均可直接复用。

菜单：局内和局外是两套逻辑 菜单

  • 局内菜单（背包、技能树）：不超过 2 次点击到达目标，支持暂停/ rayas 半暂停。
  • 局外菜单（主城、设置、商店）：信息密度可以高，但要稳定的层级和一致的返回路径。
  • 背包网格推荐正交网格 + 稀有度描边 + 数量角标 + tooltip 详情（悬停 / 长按）。
  • 每屏至少有明确退出路径；手柄/键盘/触屏三者的「返回」键位要各自正确。
backpack 背包 library 图鉴 sliders 设置

触屏交互：手势要有兜底 触屏

  • 虚拟摇杆跟随触发（碰到屏幕任意位置生成）比固定位置更友好；死区 8–12%。
  • 按钮 ≥ 48dp，相邻按钮间距 ≥ 8dp；视觉小图标也要有大热区。
  • 多指并发要处理（移动 + 射击同时）；手指数量限制写在说明里。
  • 长按 / 拖拽 / 双击都要有等效的显式按钮，别让手势成为唯一入口。
  • 边缘防误触：底部托盘、系统手势边缘区的滑入要有确认或 ≥ 12dp 的触发阈值。
hand 手势 move 移动 rotate 摇杆

颜色与反馈：把「爽感」系统化 反馈

  • 稀有度配色约定俗成：灰 → 绿 → 蓝 → 紫 → 橙/红，不要自创六色体系。
  • 增益用暖亮色 + 上浮动效，减益用冷暗色 + 抖动/闪烁。
  • 命中反馈三件套：闪白 + 数字飘字 + 命中停顿（hitstop 30–80ms）。
  • 屏幕震动要给开关和强度滑条（晕动症玩家必须能关）。
  • 所有反馈 ≤ 300ms 收尾，持续 GIF 式的光污染会让人疲劳。
sparkles 特效 flame 燃烧 zap 电击

字体：数值可读性是硬指标 字体

  • 数值（伤害、金币）用等宽/ tabular 数字，否则跳字；像素风格要有 8/16px 对齐。
  • 中文叙事文本用黑体系（圆体会削弱严肃感），按钮短标签可用圆体。
  • 字体预算：中文常用字集子集化通常 1.5–3MB，超大字库考虑位图字或用系统字。
  • 小字号（≤ 14px）避免细体 + 高笔画密度；必要时用描边提升可读性。
type 字体 hash 编号 bold 强调

新手引导：教会一件事再给下一件 引导

  • 渐进式：核心操作用强制小步骤，次要功能用被动提示（小红点 / 侧边 tips）。
  • 蒙层引导必须能跳过，且跳过后在帮助中心能重新找回。
  • 手势引导用动画演示而非大段文字；一次只教一个手势。
  • 避免一次性弹出五个红点：主线只留一个，其余收进「任务」列表。
graduation 教学 lightbulb 提示 map 路径

多分辨率、多语言与本地化 适配

  • 9-slice / 矢量优先：面板用九宫格拉伸，图标优先矢量，避免为每个分辨率切一版 PNG。
  • 宽高比从 16:9 到 21:9（甚至 4:3 平板）都要测：用锚点 + 安全区而不是写死坐标。
  • 文本膨胀预留 30–40% 空间（英文译俄语/德语）；RTL 语言要做镜像布局。
  • UI 资源分档 @1x/@2x/@3x，低端机走低档，别一律塞最高清。
  • 深色底配高饱和图标在户外强光下会糊成一团，记得实机到阳光下验一遍。
