一句话说清「这站是干嘛的」 定位

网站（区别于 Web App）的核心任务是说服 + 引导：让用户 5 秒内知道你是谁、能帮他什么、然后点那个按钮。

  • 主标题写结果而不是能力：「3 分钟做出数据看板」优于「专业的 BI 平台」。
  • 首屏三件事：价值主张 / 社会证明 / 一个主 CTA。
  • 导航项控制在 5–7 个；超过就把次要项收进「更多」或页脚。
  • 每个页面解决一个任务：首页说服、定价页转化、文档页降低门槛、博客留搜索流量。
rocket 启动 target 目标 users 用户

首屏：折叠线以上的信息密度最高 首屏

  • 关键信息必须在不滚动就能看到的位置：标题、副标题、CTA、可信证据。
  • LCP（最大内容绘制）目标 < 2.5s；首屏不要放自动播放的大视频。
  • CTA 用实心高对比按钮，页面上只有一个主 CTA；次要用幽灵按钮。
  • 导航栏吸顶时高度压到 56–64px，避免吃掉过多视口。
monitor 首屏 mouse 点击 star 亮点

响应式：断点跟着内容走 响应式

断点宽度典型处理
手机360–767单列、导航收汉堡菜单、字号不缩
平板768–1023两列卡片，导航可保留部分项
笔电1024–1439容器宽 1200，三列
大屏≥1440容器封顶 1280，避免拉长行宽
  • 优先写移动端样式，再用 media query 向上增强。
  • 图片必用 srcset + sizes + loading="lazy"，格式 AVIF/WebP。
  • 地图、第三方 iframe 在移动端要有最小高度，避免挤压布局。
smartphone 手机 tablet 平板 monitor 桌面

排版：读得下去才是好设计 排版

  • 正文行宽 60–75 字符（中文 30–40 字），段落间距 ≥ 1.5 倍字号。
  • 标题层级压差要明显：H1 32–48 / H2 24–32 / H3 20–24，相邻两级差距至少 1.25 倍。
  • 正文颜色别用纯黑 #000，用 #1F2430 之类；行高 1.6–1.75。
  • 中英混排在英文两侧加空格，标点用全角；重要数字用 tabular-nums 对齐。
text 文本 heading 标题 quote 引用

CTA 与转化按钮 转化

  • 动词 + 收益：「免费生成图标」比「提交」点击率高得多。
  • 按钮高度 ≥ 44px（移动端 48），左右内边距 ≥ 24px。
  • 同屏不出现两个同权重按钮；重复 CTA 至少间隔一屏以上。
  • 表单字段只问必需的：每多一栏都掉一层转化。
cursor 点击 cart 下单 card 支付

导航结构：别让用户找路 导航

  • 顶栏用于「全局」，侧边用于「当下上下文」，面包屑用于「层级」。
  • 长页面加锚点目录（本页顶部就有），并高亮当前所在章节。
  • 页脚不是垃圾桶：分 3–5 组列出产品/资源/公司/法律，并放版权与备案。
  • 移动端菜单里的 CTA 要保留，别折叠掉转化入口。
menu 菜单 chevron 层级 anchor 锚点

图片、插画与视频 媒体

  • 统一比例：卡片图 16:9 或 4:3，头像 1:1，插图留够边距。
  • 永远设置 width/height 或 aspect-ratio，否则图片加载会抖版面（CLS）。
  • 不要把文字烧进图片——SEO、翻译、无障碍三输。
  • 视频直播给海报帧 + 静音自动播放 + 明确播放控件。
image 图片 play 视频 camera 摄影

动效：200–300ms 就够 动效

  • 界面动效 150–300ms；超过 400ms 会明显感觉「卡」。
  • 缓动用 cubic-bezier(.2,.8,.2,1) 或 ease-out，别用 linear。
  • 入场动效要有位移 + 淡入，纯淡入会显得没重点；列表错开 30–50ms。
  • 支持 @media (prefers-reduced-motion: reduce) 关闭动画。

性能预算：卡的本质是字节 性能

指标及格优秀
LCP 最大内容绘制< 2.5s< 1.8s
CLS 布局偏移< 0.1< 0.05
INP 交互响应< 200ms< 100ms
首屏 JS< 300KB< 150KB
  • 字体做子集 + woff2 + font-display:swap；图标用 SVG 或图标字体子集。
  • 首屏 hero 图控制在 150–250KB；整页图片总预算尽量 < 1MB。
  • 第三方脚本（统计、聊天）延后加载或直接异步，别阻塞首屏。
gauge 性能 activity 指标 clock 时间

SEO 与分享 SEO

  • 每个页面唯一的 <title>（≤ 60 字符）和 description（≤ 160 字符）。
  • Open Graph / Twitter Card 预览图 1200×630，否则分享出去是灰块。
  • canonical 去重、sitemap.xml、robots.txt、结构化数据（Product / Article / FAQ）。
  • H1 每页只有一个，标题层级不跳级（H2 直接到 H4 是错误）。
search 搜索 globe 网站 link 链接

合规与可信 合规

  • 全站 HTTPS；外部链接加 rel="noopener"（本仓库所有外链已如此）。
  • Cookie / 埋点提示：拒绝和接受按钮权重相同，别只有「同意」。
  • 隐私政策、条款、联系方式必须可达；国内站点注意ICP 备案与等保要求。
  • 展示 Logo 时注意商标属性：品牌素材多为 CC0/CC-BY 许可，但商标权不随许可转让。
