联网版 约 2 MB

只装外壳和检索索引，搜到哪才下载哪：命中后自动从仓库拉对应数据块并存在本机。
优点：秒装、随时更新、体积几乎可以忽略。
适合：日常查图标、只需要其中十几套的人。

离线版 约 100 MB

215 套图标库 + 797 个应用图标 PNG 全部打包进安装包，装完断网也能完整使用。
优点：飞机上、内网、出差路上都照常用。
适合：离线环境、需要整库比稿、不想等加载的人。

安装包由 GitHub Actions 每次发布自动构建并上传到 Releases。若某个文件还没生成，可到 Actions 里下载同名构建产物。

常见问题

  1. 联网版和离线版内容一样吗？一样。只是数据到达本机的时机不同：一个是边用边下，一个是安装时就全给你。
  2. 离线版会旧吗？会跟随发布版本。图标库有新增时我们会重新发版，重装即可。
  3. 「我的 → 已下载」是什么？联网版里被缓存下来的数据块清单，看过的图标库会一条条累积，之后再断网也能看。
  4. 许可证？图标素材版权归各上游项目所有，请以每个集合上游的实际许可证为准，完整清单见 README 与仓库 LICENSE。
