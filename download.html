Online edition ~2 MB

Installs only the shell and the search index — data is fetched as you search: matches are pulled from the repo and cached locally.
Pros: instant install, always up to date, negligible size.
Best for: everyday icon lookups when you only need a dozen or so sets.

Offline edition ~100 MB

All 215 icon sets plus 797 app icon PNGs are bundled into the installer, so it works fully offline.
Pros: works on a plane, on an intranet, or on the road.
Best for: offline environments, comparing across the whole library, no waiting for loads.

Installers are built and uploaded to Releases automatically by GitHub Actions on every release. If a file is not there yet, grab the artifact with the same name from Actions.

FAQ

  1. Is the content the same in both editions? Yes. Only the timing differs: one downloads as you go, the other ships everything at install time.
  2. Does the offline edition go stale? It tracks the release version. When icon sets are added we cut a new release — just reinstall.
  3. What is "My → Downloaded"? The list of data shards cached by the online edition. Sets you have viewed accumulate one by one, and stay viewable offline afterwards.
  4. Licensing? Icon assets belong to their upstream projects; follow the license of each upstream set. See the README and the repository LICENSE for the full list.
